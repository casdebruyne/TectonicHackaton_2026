# SD WORX APPLICATION

**Know what you can trust, before you use it.**
A Streamlit app that assesses the reliability of documents with a transparent score from 1 to 100 and stores them in a searchable knowledge base.

## Launch the app here!

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://tectonichackaton2026-wtiard6rvzwqny5qdv29qj.streamlit.app/)

## ✨ Why this app?

Organisations collect knowledge in PDFs, Word files, spreadsheets and images, but nobody knows how reliable those sources are. Is the document still up to date? Who wrote it? Was it generated by AI?

This app answers those questions in three steps and gives every document an **explainable score**: you see exactly why a document receives 82 or 34 points.

## 🚀 Features

| Page | What can you do? |
|---|---|
| **1️⃣ Upload** | Upload multiple files at once (PDF, Word, Excel, images) and fill in the subject, author, language, country and AI percentage for each document |
| **2️⃣ Assess & save** | Automatically calculate a score, see the reasoning per factor, and save everything to the database |
| **3️⃣ Search** | Search by subject, file name or author, filter by language, country and minimum score, and export to CSV |

## 🧮 How does the score work?

The score consists of five factors with fixed weights (100 points in total). This keeps every score fully explainable.

| Factor | Max. points | Logic |
|---|---:|---|
| **Recency** | 30 | Based on the modification date from the metadata. Decreases linearly to 0 after 3 years. Unknown date = low score |
| **Author** | 20 | Full points if the entered name matches the file's metadata, partial points if the name cannot be verified, nothing if the author is missing |
| **AI percentage** | 25 | The more AI-generated, the lower the score |
| **Metadata present** | 15 | The file contains readable metadata (date) |
| **File type** | 10 | PDF > Word > Excel > images |

**Rating**

- 🟢 **Reliable**: score ≥ 75
- 🟠 **Be careful**: score 50 to 74
- 🔴 **Do not trust**: score < 50


## 🧱 Tech stack

- [Streamlit](https://streamlit.io/): interface
- [pandas](https://pandas.pydata.org/): data processing
- [SQLite](https://www.sqlite.org/): storage
- pypdf, python-docx, openpyxl

## ⚠️ Limitations

- The **AI percentage** is currently entered manually; there is no automatic AI detection yet.
- **Metadata can be altered or forged**. The score is a well-founded indication, not a guarantee.
- The **weights** are a deliberate choice and can be adjusted in the `GEWICHTEN` dictionary.

## 🗺️ Possible extensions

- Automatic AI detection instead of a manual slider
- Content analysis of the text (source citations, consistency)
- User accounts and a shared database
- Adjustable weights via the interface
